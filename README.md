# language-regex

Syntax highlighting for regular expressions and replacement templates.

## Features

- **Grammars**: provides Tree-sitter grammars built from [tree-sitter-regex](https://github.com/tree-sitter/tree-sitter-regex) and [tree-sitter-regex-sub](https://github.com/lumine-code/tree-sitter-regex-sub).
- **Shared injections**: supplies one regular-expression parser to JavaScript, TypeScript, and Ruby.
- **Search fields**: highlights patterns and replacement templates in Find and Replace.
- **Replacement references**: distinguishes capture, whole-match, and escaped-dollar substitutions.

## Installation

To install `language-regex` search for it in the Install pane of the Lumine settings, or run the command `lumine --install lumine-code/language-regex`.
